# 校园论坛

一个为校园场景打造的轻量级论坛系统。**纯 PHP 编写，零框架、零 Composer 依赖**，上传即用，专为免费虚拟主机（无 cron、无命令行）环境设计。

- 前台：发帖 / 楼中楼回复 / 点赞 / 站内消息 / 邮件通知 / 图片与视频上传 / 正文链接自动识别 / 第三方登录 / 双热榜 / 板块浏览 / 弹窗公告
- 后台：仪表盘 / 系统设置 / 帖子管理 / 公告管理（帖子 · 推送 · 弹窗多渠道）/ 消息推送 / 数据统计 / 板块管理 / 账号管理
- 移动端：针对手机专门适配（触控目标 ≥44px、安全区留白、底部滑入弹窗、输入防缩放、导航栏固定底部液态玻璃胶囊栏）

当前版本：**v1.4.2 Beta**

## 功能特性

### 前台

| 模块 | 说明 |
| --- | --- |
| 发帖 / 回复 | 标题选填、正文必填；支持楼中楼回复，层层缩进、默认收起，无回复上限 |
| 点赞 / 分享 | 帖子与回复均可点赞；分享到微信 / QQ 展示为卡片（OG meta） |
| 站内消息 | 收到点赞 / 回复时即时通知，导航铃铛 10 秒轮询；接收官方推送 |
| 邮件通知 | 点赞 / 回复 / 公告推送按 30 分钟窗口聚合为一封 HTML 邮件，防打扰、防主机超时 |
| 图片 / 视频上传 | 发帖可上传图片或视频至第三方图床（img.scdn.io），调用系统文件选择器，带上传进度；正文只插入缩略图与占位符，不暴露外链 |
| 正文链接自动识别 | 正文中的完整链接、`www.` 开头及常见域名后缀的裸网址自动转为可点击超链接（裸域名自动补 `https://`），图片链接直接渲染为图片 |
| 登录方式 | 邮箱 + 密码、展示 ID + 密码、第三方登录（微信 / QQ / 抖音 / 微软，可单个启用 / 关闭） |
| 邮箱绑定 | 第三方登录账号可绑定真实邮箱并验证；未绑定时仅支持 ID 与第三方登录 |
| 板块浏览 | 顶部导航「版块」下拉进入板块页（含「全部帖子」总览），按钮显示当前板块名；板块页版面内卡片无圆角，支持按时间 / 热度排序 + 时间段筛选，每页 10 条分页跳转 |
| 热榜 | 主页「最新动态」固定展示最新 6 帖（可跳转全部帖子），另有帖子热度 TOP10 与作者榜 TOP10（可自选按发帖数 / 获赞数 / 被评论数排行） |
| 弹窗公告 | 打开页面时弹出公告，支持跳转按钮，同一用户对同一公告只弹一次 |
| 移动端导航 | 手机（≤760px）访问时主导航固定于屏幕底部，呈「液态玻璃」胶囊栏（半透明 + 背景模糊 + 高光描边 + 柔和投影），图标在上文字在下、单项触控 ≥52px；「版块」下拉菜单向上弹出 |
| 其他 | 加载动画、图片灯箱、深色页脚（关于 / 捐赠 / 友情链接，后台可配） |

### 后台

- **仪表盘** — 站点概览
- **系统设置** — 全站开关统一为左右滑动开关，含论坛总开关、站内消息、图片与视频上传、注册开关、邮件通知分类开关、聚合登录单通道开关、调试模式、极验、SMTP、图床（含视频上限）、页脚等
- **帖子管理** — 搜索、删除、标记 / 取消公告帖
- **公告管理** — 一篇公告可同时投放到「帖子 / 推送 / 弹窗」多个渠道，可带跳转按钮
- **消息推送** — 只填标题 + 内容即可向全部用户即时推送站内通知，附最近推送记录
- **数据统计** — 点赞 / 发帖等曲线统计，支持时间筛选
- **板块管理** — 板块增删改（存于配置，非硬编码）
- **账号管理** — 封禁 / 禁言 / 重置密码、身份设置

### 权限体系

三种身份可叠加拥有，「官方」身份仅超级管理员可赋予：

| 身份 | 权限 |
| --- | --- |
| 官方 official | 处理投诉举报、审阅运营处理结果、发布公告、推送消息、编辑板块 |
| 运营 operator | 处理投诉举报、管理帖子、发布公告、推送消息、编辑板块 |
| 管理员 admin | 处理投诉举报、管理账号（封禁 / 禁言 / 重置密码）、系统设置 |

超级管理员：`admin@school.cn`（预置账号，拥有以上全部权限）。

> 后台入口为 `/admin/`。前台登录不会自动进入后台，只有通过后台登录页登录的会话才可进入。

## 技术栈

- **语言**：PHP ≥ 7.4（已在 PHP 8.5 上验证）
- **数据库**：PDO — MySQL 为主，SQLite 兜底（双驱动字段类型自动适配）
- **依赖**：无。无框架、无 Composer、无构建步骤
- **前端**：原生 HTML / CSS / JavaScript，无打包工具
- **配置**：`config.php` 提供默认值，`_data/settings.json` 由后台写入覆盖

## 快速开始

### 1. 上传源码

将全部文件上传到网站根目录（或子目录，程序会自动识别 `app_base_path()`）。

### 2. 确保 `_data` 可写

```bash
chmod -R 755 _data
```

### 3. 配置数据库

编辑 `config.php`，修改数据库相关配置：

```php
'db_type'       => 'mysql',              // sqlite | mysql
'db_mysql_host' => 'localhost',
'db_mysql_name' => 'your_database_name',
'db_mysql_user' => 'your_database_user',
'db_mysql_pass' => 'your_database_password',
```

若使用 SQLite，只需将 `db_type` 改为 `sqlite`，数据文件会自动创建在 `_data/forum.db`。

### 4. 运行环境自检

浏览器访问：

```
https://你的域名/install.php
```

页面会检查 PHP 版本、PDO 驱动、`_data` 写权限，并自动建表。全部通过后即可进入前台或后台。

### 5. 登录后台并修改默认密码

```
https://你的域名/admin/
```

预置账号：

| 账号 | 密码 |
| --- | --- |
| `admin@school.cn` | `123456` |

> **请登录后立即修改默认密码。**

### 6. 建议的上线前配置

在「系统设置」中完成：

1. **调试模式** → 关闭（`debug_mode`）
2. **验证码回显** → 关闭（`mail_debug_show_code`）
3. **SMTP** → 配置邮件服务器（否则站内消息不发邮件）
4. **素颜聚合登录** → 填写 `appid` / `appkey`，并按需勾选要开放的登录通道
5. **极验 v4** → 填写 `captcha_id` / `captcha_key`（可选）
6. **图床** → 默认使用 img.scdn.io 公共 API，开箱即用，无需 Token
7. **板块 / 页脚** → 按需调整

## 配置说明

配置分两层，优先级：`_data/settings.json` > `config.php` 默认值。

- **推荐**：全部通过后台「系统设置」修改，会自动写入 `_data/settings.json`，无需改代码。
- **首次部署**：需手动编辑 `config.php` 填写数据库信息。

主要配置项：

| 配置项 | 说明 |
| --- | --- |
| `db_type` | 数据库类型：`mysql` / `sqlite` |
| `site_url` | 站点地址，留空自动识别；绑定域名后建议填写 |
| `debug_mode` | 调试模式，开启后显示详细错误，**上线请关闭** |
| `mail_debug_show_code` | 验证码回显，仅测试用，**上线请关闭** |
| `enable_forum` / `enable_msg` / `enable_upload` / `enable_register` | 功能总开关 |
| `suyan_channels` | 已启用的聚合登录通道，如 `["wx","qq","douyin","microsoft"]`，可逐个增删 |
| `cdn_api` / `cdn_domain` / `upload_max_mb` / `upload_video_mb` | 图床接口、CDN 域名、单图大小上限、视频大小上限 |
| `notify_poll_secs` | 铃铛轮询间隔（秒） |
| `mail_digest_mins` | 邮件聚合窗口（分钟） |
| `boards` | 板块列表 |

## 常见问题

**Q：数据库表结构会自动升级吗？**
会。程序每次连接时执行幂等的 `CREATE TABLE IF NOT EXISTS` 与 `ALTER TABLE`（try/catch 包裹），旧版本升级后直接访问即可，无需手动执行 SQL。

**Q：为什么公告推送的邮件不是立即发送？**
为避免虚拟主机群发邮件超时，推送通知的邮件会以 `mailed=2` 标记，交由前台流量的聚合摘要统一发送（默认 30 分钟窗口合并）。站内消息本身是即时送达的。

**Q：图片上传失败？**
检查「系统设置 → 图床」的 API 地址与单图上限，同时确认主机 `upload_max_filesize` / `post_max_size`。调试模式下会回显具体错误。

**Q：视频上传后为什么变成了 GIF / WebP？**
本项目使用的 img.scdn.io 图床对视频仅输出 GIF 或动态 WebP 动图，且限制在 10 秒以内（超出自动裁切）。视频大小上限可在「系统设置 → 图床 → 视频上限」调整。

**Q：发帖时为什么正文里看不到图片链接？**
v1.4.2 起，上传后正文只插入占位符与缩略图，真实外链保存在表单隐藏域中，由服务端在提交时还原，避免误删链接导致图片丢失。

**Q：第三方登录不生效？**
需在「系统设置 → 素颜聚合登录」填写 `appid` / `appkey`，并确保回调地址为 `oauth.php`。

**Q：忘记超管密码？**
直接操作数据库 `users` 表，将 `admin@school.cn` 的 `password_hash` 更新为新的 `password_hash('新密码', PASSWORD_DEFAULT)` 值。
