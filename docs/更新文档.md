2026.9.19    v1.4.1 正式版

更新公告：

本次更新为「移动端体验 + 公告体系」专项版本。重点做了三件事：为手机端重新设计界面、把后台开关改成更直观的左右滑动开关、把公告升级为「帖子 / 推送 / 弹窗」多渠道投放，并新增后台直接推送消息的入口。

一、移动端专门设计（手机优先）

1.触控目标全面加大：所有按钮、导航项、图标按钮、点赞 / 分享 / 回复操作的最小可点区域统一提升到 44×44px 以上，相邻操作之间留出间距，拇指点按不再「点错、点不中」。
2.底部安全区适配：顶部导航补齐刘海屏安全区留白，页脚、弹窗、悬浮按钮（发帖 FAB）自动避让手机底部手势条，内容不会被系统栏遮挡。
3.表单防缩放：手机端输入框字号统一为 16px，聚焦时 iOS 不再自动放大页面；输入框高度加大到 48px 左右，选板块、选时间段等下拉控件同样加高。
4.弹窗公告改为底部滑入：手机端公告从屏幕底部平滑升起，卡片高 88vh、圆角上翻，主按钮通栏显示，单手即可完成关闭或查看详情。
5.卡片与列表优化：帖子卡片头像与操作区加大，热榜条目、分页器、分段选择器（排序 / 时间段）全部补足点击高度。
6.超小屏专项（≤400px）：进一步压缩左右留白，保证小屏手机上的信息密度与可读性。
7.后台移动端同步适配：手机进入后台时，侧栏收起为横向滑动的胶囊导航；表格支持横向滚动；设置项开关尺寸进一步加大；保存按钮自动铺满一行，不再挤压。

二、后台设置改为左右开关

1.后台「系统设置」中所有复选框统一改为 iOS 风格的左右滑动开关（灰=关、蓝=开），带滑动动画，点击文字区域也可切换，符合手机直觉。
2.功能开关按从属关系分组展示：「论坛总开关」为主开关，站内消息、图片上传作为子开关缩进显示，主开关关闭时子项状态一目了然。
3.每个开关下方保留一行小字说明，明确该开关打开后会发生什么，避免误操作。

三、公告支持多渠道投放（帖子 / 推送 / 弹窗）

1.公告编辑页新增「投放渠道」区，提供三个左右开关，可任选一个，也可任意组合，同一篇公告可同时投放到多个渠道。
2.帖子渠道：在「公告」版块生成一篇公告帖，可带一个跳转按钮（文字 + 地址）。
3.推送渠道：保存后立即向全部启用用户发送站内通知（前台导航铃铛处可见），邮件按「系统设置 → 邮件通知聚合」的窗口合并发送，避免主机超时。
4.弹窗渠道：用户打开前台页面时弹出公告卡片（标题 + 内容 + 跳转按钮），同一用户对同一篇公告只弹一次，关闭后不再打扰。
5.公告列表新增「投放渠道」列，用彩色标签直观展示每篇公告投放到了哪些渠道（帖子=蓝、推送=紫、弹窗=绿），未选任何渠道的显示「仅存档」。

四、新增前台弹窗公告

1.弹窗展示最新的、处于「展示中」且勾选了「弹窗」渠道的公告。
2.弹窗带「公告」徽标、标题、正文（支持换行）与按钮区；有关联链接时显示跳转按钮，否则仅显示「我知道了」。
3.支持三种关闭方式：点击「我知道了」、点击卡片外遮罩、按 Esc 键；关闭后通过浏览器本地存储记忆，刷新页面不再重复弹出。
4.打开弹窗时锁定页面滚动，关闭后自动恢复；按钮与关闭按钮均满足移动端点击尺寸。

五、后台可直接推送消息（新增独立推送页）

1.后台侧栏新增「消息推送」菜单（移动端为「推送」），与公告管理分开，专职做即时推送。
2.只需填写「推送标题」和「推送内容」两项即可发送，另可选填一个跳转链接；填写链接后会附在消息末尾，方便用户点击查看详情。
3.推送前弹出确认框，明确提示将送达的用户数量；推送后页面显示成功送达人数。
4.页面下方展示「最近推送记录」（最近 8 条），便于回溯已推送的内容。
5.推送的数据量与异常已做容错：用户较多时分批写入，单批 200 人，避免一次性插入导致超时。

UI：

1.新增左右开关组件：48×28px 滑轨 + 22px 圆形滑块，开启为品牌蓝，支持键盘聚焦高亮，并尊重系统「减少动态效果」设置；手机端放大到 52×30px。
2.新增弹窗公告组件：半透明遮罩 + 模糊背景，桌面端居中弹出、手机端底部滑入，含淡入与上滑两段动画。
3.公告列表渠道标签：帖子（蓝）/ 推送（紫）/ 弹窗（绿）/ 仅存档（灰）。
4.后台移动端导航改为横向滑动的胶囊样式，选中项蓝底高亮。

修复 / 优化：

1.统一移动端断点策略：前台 760px（含 400px 超小屏），后台 860px（含 420px 超小屏），避免平板与折叠屏设备出现中间态错位。
2.修复后台表格在手机上撑破容器的问题，改为容器内横向滚动，并去掉表格换行挤压。
3.优化后台表单在手机端「标签与输入框同行导致输入框过窄」的问题，改为上下排列、输入框通栏。

涉及文件：
新增：admin/push.php
修改：common.php、footer.php、admin/head.php、admin/announcements.php、admin/settings.php、assets/style.css、assets/admin.css

部署说明：
1.数据库无需手动升级：程序在连接时会自动为公告表补充渠道字段（chan_post / chan_push / chan_popup 等），幂等执行，可反复访问，不会影响已有数据。
2.历史公告默认没有勾选任何渠道，会在列表中显示为「仅存档」；如需重新投放，编辑该公告并勾选渠道后保存即可。
3.推送与公告的邮件依赖「系统设置 → 邮箱 / SMTP」配置；未配置 SMTP 不影响站内消息推送，仅不发邮件。
4.建议部署后用手机实际访问前台与后台各一次，确认底部安全区、开关与弹窗展示符合预期。
